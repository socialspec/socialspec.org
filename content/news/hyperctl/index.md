> **Tuesday, October 13, 2026** &mdash; The latest release of the HyperTexting CLI (`hyperctl`) includes first-class support for @contactspec.org. 
> 
> Check out the new [`site.contact` reference documentation], or visit @hypertexting.dev to learn more.

One of my favorite things about the @followspec.org, @aboutspec.org, and @contactspec.org is that each API follows a simple principle: [single purpose, single file, single request](/news/why-well-known-uris/#the-goal).

In practice that means most static site generators such as [HyperTexting], [Hugo], [Astro], and [11ty] (nay, [Build Awesome]?) all offer zero-day support for SocialSpec.
<mark>Just add `following.opml`, `about.md`, and/or `contact.vcf` files to the `public/.well-known/` or `static/.well-known/` directory and you're done.</mark> 
Boom. :boom: 

But managing SocialSpec data as static files is only one possible approach.
And even though SocialSpec data files can be generated by exporting an OPML subscription list from your RSS feed readers or podcast apps, or exporting a vCard from your contacts apps, that is still an extra step. 

With `hyperctl` v0.24.0, the HyperTexting project demonstrates a more integrated approach via its new [`site.contact`] property. 
When populated, `hyperctl` will generate a @contactspec.org contact card at `/.well-known/contact.vcf`. 

### Example

```yaml
---
title: Caleb Hailey
description: HyperText junkie. RSS prosumer. Founder @herdworks.com. 🌹⚽️
...: ...
contact:
  name: 
  favicon:
  email:
    - label: Personal
      address: hello@calebhailey.com
      preferred: true
  phone: []
  social:
    - service: iMessage
      username: hello@calebhailey.com
    - service: FaceTime
      href: facetime://hello@calebhailey.com
    - service: Bluesky
      href: https://bsky.app/profile/calebhailey.com
  links:
    - label: Personal
      href: https://calebhailey.com
    - label: Old blog
      href: https://sheesh.blog
```

That's pretty great!

For more information about the new @contactspec.org integration in the HyperTexting CLI, visit the [`site.contact` reference documentation]. 
To learn more about the HyperTexting CLI, please visit https://hypertexting.dev.
